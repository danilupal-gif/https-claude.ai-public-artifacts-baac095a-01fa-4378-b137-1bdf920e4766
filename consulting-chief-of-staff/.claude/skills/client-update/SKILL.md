# Weekly client update

1. Read `memory/clients/<client>.md` and the client's emails and call notes from the past week.
2. Draft an email of 150 words or less:
   - **Done this week:** milestones reached, in plain outcomes ("payments now start onboarding on their own")
   - **Next week:** what's coming
   - **Needed from you:** specific items, each with a date
   - **Wins or numbers:** only measured results; say if a number is early
3. Follow the "protect the method" rule: no tool settings, workflow logic, prompts or build steps.
4. Create a Gmail draft to the client if possible; otherwise save to `briefings/update-YYYY-MM-DD-<client>.md`. Don't send.
5. Add a dated line to the client file: "Update drafted".
